# The knowledge base

*What this studio knows about the creator's niche, kept by the chats. Every fact has a source, a date and a reliability grade
(`standard/research/FOOTAGE_SOURCING.md` and the research rules in `rules/SHARED.md`). A new chat reads this file, then what the next
video needs.*

## How it is built
- **Facts:** one file per subject (`kb/<subject>.md`): the fact, its primary source (link), the date it was checked, the grade.
  Research for a video lands here first, so the next video starts from it.
- **Sources and footage:** `kb/FOOTAGE.md` (the map of the creator's material: where each kind of picture lives, what each source
  shows) and `kb/footage/` (the footage brain's sources list and how to build its index).
- **Used music:** `kb/MUSIC_USED.md` (the tracks finished videos used, so the next videos start from what worked).
- **The niche's words:** `kb/LINGO.md` (how the niche's top creators talk, from their captions; `standard/research/LINGO.md` says how).

## Researched up to
(date) — the newest date the facts here were checked. Research before a video covers the days since.
